## 关键原文摘录

**鄂价费〔2008〕5号：**

> 1. 离婚案件每件交纳200元。涉及财产分割，财产总额不超过20万元的，不另行交纳；超过20万元的部分，按照0.5％交纳。
> 2. 侵害姓名权、名称权、肖像权、名誉权、荣誉权及其他人格权的案件，每件交纳300元。涉及损害赔偿，赔偿金额不超过5万元的，不另行交纳；超过5万元至10万元的部分，按照1％交纳；超过10万元的部分，按照0.5％交纳。
> 3. 其他非财产案件每件交纳80元。
> 4. 知识产权民事案件：没有争议金额或者价额的，每件交纳1000元。
> 5. 当事人提出案件管辖权异议：异议不成立的，每件交纳80元。

**民诉法解释第206条：**

> 人民法院决定减半收取案件受理费的，只能减半一次。

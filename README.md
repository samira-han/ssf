# 武汉诉讼费计算器 · 资料包

> 一个给武汉当事人、法援志愿者和基层法律工作者用的诉讼费估算工具。**双击 HTML 就能用，离线、无依赖、手机也能开。**
>
> 数据基准：**2026-10-28**。依据：《诉讼费用交纳办法》（国务院令第481号）+ 湖北省鄂价费〔2008〕5号 + 民诉法解释第206条。

## 二、网页版怎么用

1. 双击 `武汉诉讼费计算器.html`，用 Chrome / Edge / Safari 打开。
2. 先选“起诉 / 上诉”或“申请事项”，再点具体类型。
3. 填金额；如有简易程序、调解、撤诉等情形，在“本诉是否有减半情形”里选一项。有反诉 / 有独立请求权第三人时，勾选后另填其独立请求金额。
4. 右侧实时出结果；可“复制明细”或“打印 / 存 PDF”。

初始页面填的是 **10 万元示例**（算出 2,300 元），直接改成你的金额即可。

覆盖 14 类：

- **起诉 / 上诉（案件受理费）**：财产案件、离婚、人格权、劳动争议、知识产权、行政、其他非财产、管辖权异议。
- **申请事项（申请费）**：申请执行、财产保全、支付令、公示催告、撤销仲裁裁决 / 认定仲裁协议效力、破产申请。
- **反诉 / 有独立请求权第三人**：财产案件和有争议金额的知识产权案件，可另填独立请求金额；该份受理费单独计算后减半，本诉仍按本诉金额计算。

结果会区分“案件受理费 / 申请费”，并提示预交时点；保全费自动封顶 5,000 元，破产申请费自动封顶 30 万元。

## 三、命令行怎么用

需要 Node.js（建议 18+）。在送检包解压目录下：

```bash
# 财产案件：100 万元
node tools/wuhan-litigation-fee.mjs property 1000000

# 简易程序减半；金额也可以写“万”
node tools/wuhan-litigation-fee.mjs property 50万 --half simple

# 离婚：财产总额 50 万元；不涉及财产分割用 --no-property
node tools/wuhan-litigation-fee.mjs divorce 500000
node tools/wuhan-litigation-fee.mjs divorce --no-property

# 人格权：索赔 10 万元
node tools/wuhan-litigation-fee.mjs personality 100000

# 劳动争议、无争议金额的知识产权
node tools/wuhan-litigation-fee.mjs labor
node tools/wuhan-litigation-fee.mjs ip --no-amount

# 执行 50 万元 / 没有执行金额
node tools/wuhan-litigation-fee.mjs execution 500000
node tools/wuhan-litigation-fee.mjs execution --no-amount

# 保全 100 万元（会显示封顶 5,000 元）
node tools/wuhan-litigation-fee.mjs preservation 1000000

# 支付令、公示催告、撤销仲裁、破产
node tools/wuhan-litigation-fee.mjs payment-order 100000
node tools/wuhan-litigation-fee.mjs public-notice
node tools/wuhan-litigation-fee.mjs arbitration
node tools/wuhan-litigation-fee.mjs bankruptcy 10000000

# 全部类型代码 / 机器可读
node tools/wuhan-litigation-fee.mjs list
node tools/wuhan-litigation-fee.mjs property 1000000 --json
```

本诉减半参数：`simple`（简易程序 / 小额诉讼）、`mediation`（调解）、`withdrawal`（撤诉），同一份受理费只减一次。反诉 / 第三人另用 `--counterclaim <金额>` 单独计费后减半，例如：

```bash
node tools/wuhan-litigation-fee.mjs property 100万 --counterclaim 50万
# 本诉 13,800 + 反诉 4,400 = 18,200 元
```

**同源机制：** 命令行工具运行时读取 HTML 里的 `<script id="fee-engine">`，与网页共用 `DATA` 和纯计算函数。改费率优先改网页内“基础数据”，CLI 自动跟随；页面文案中的硬编码金额需同步检查。

## 四、武汉 / 湖北标准速记

### 案件受理费

| 类型 | 湖北标准 |
|---|---|
| 离婚 | 每件 **200 元**；财产总额 >20 万元的部分按 **0.5%** |
| 人格权 | 每件 **300 元**；赔偿 >5 万元至 10 万元部分 **1%**，>10 万元部分 **0.5%** |
| 其他非财产 | 每件 **80 元** |
| 知识产权（无争议金额） | 每件 **1,000 元** |
| 劳动争议 | 每件 **10 元** |
| 行政 | 其他 **50 元**；商标、专利、海事行政 **100 元** |
| 管辖权异议（不成立） | 每件 **80 元** |

财产案件按诉讼请求金额分段累计：1 万元以内 50 元；1 万–10 万 2.5%；10 万–20 万 2%；20 万–50 万 1.5%；50 万–100 万 1%；100 万–200 万 0.9%；200 万–500 万 0.8%；500 万–1000 万 0.7%；1000 万–2000 万 0.6%；2000 万以上 0.5%。

**常用点位：** 10 万 = 2,300 元；100 万 = 13,800 元；500 万 = 46,800 元。

### 申请费

| 类型 | 标准 |
|---|---|
| 申请执行（有金额） | 1 万以内 50 元；1 万–50 万 1.5%；50 万–500 万 1%；500 万–1000 万 0.5%；1000 万以上 0.1% |
| 申请执行（无金额） | 每件 **50–500 元**，法院核定 |
| 财产保全 | 1,000 元以内 / 不涉及金额 **30 元**；1,000 元–10 万 **1%**；10 万以上 **0.5%**；**封顶 5,000 元** |
| 支付令 | 财产案件受理费的 **1/3** |
| 公示催告 | 每件 **100 元** |
| 撤销仲裁裁决 / 认定仲裁协议效力 | 每件 **400 元** |
| 破产申请 | 按财产案件标准 **减半**，**封顶 30 万元** |

> 执行申请费**不由申请人预交**，执行后由被执行人负担。保全费需预交，最终一般由申请人负担。

## 五、最容易算错的 5 件事

1. **财产案件不是全额乘一个比例。** 10 万元是“1 万以内 50 元 + 9 万 × 2.5%”，不是 10 万 × 2.5%。
2. **离婚、人格权不是按财产案件全额算。** 离婚只对超过 20 万元的财产部分加收 0.5%；人格权只对超过 5 万元的赔偿分段加收。
3. **同一份受理费只减一次。** 本诉的简易程序 + 调解 + 撤诉同时出现，也只减一次（民诉法解释第206条）。反诉 / 第三人是独立的一份受理费，按第18条单独计费后减半，不是把本诉减半。
4. **执行费通常不用先交。** 执行后由被执行人负担；不要把它和保全费混在一起。
5. **诉讼费 ≠ 律师费。** 鉴定、公告、评估、律师费不在本工具内；本工具只算案件受理费和申请费。

## 七、维护指南

1. **改费率**：优先改 `武汉诉讼费计算器.html` 中“一、基础数据”的 `DATA`；固定标准、分档、封顶都在这里，再按下条同步文案与测试。
2. **同步文案**：页面里部分说明文字含有具体金额，更新费率后搜一遍 `200`、`300`、`5,000`、`30 万` 等，改成新值。
3. **跑测试**：`node --test tests/wuhan-litigation-fee.test.mjs`；改档位后补充边界值。
4. **留证据**：新文件放 `原始快照/`，更新其 `README.md`，写明 URL 与抓取日期。
5. **改日期**：页面顶部“数据核验”、打印页头、口径卡、`DATA.version` 四处同步。

## 八、免责声明

本工具是**估算工具**，不是法院官方缴费通知，也不构成法律意见。案件类型、标的额、程序适用、司法救助、是否适用小额诉讼等都会影响最终金额。实际金额以受理法院出具的**缴费通知书**为准；有疑问拨 **12368** 诉讼服务热线，或向受理法院立案庭核对。
